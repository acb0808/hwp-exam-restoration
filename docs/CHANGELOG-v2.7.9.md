# v2.7.9 변경 내용

v2.7.9은 기존 시험지 복원 흐름을 다듬고 도형·수식·작업 이어하기 기능을 보강했습니다.

## 검수 노트와 수정 범위

- 최종 검수의 지적을 수정 대상과 사람 확인용 노트로 나눕니다. 빠진 문항, 오독, 선택지 행 배치, 잘림, 오답은 수정 대상으로 남습니다. 도형 모양이나 읽기에 영향 없는 간격 차이는 노트로 기록할 수 있습니다.
- 같은 쪽에서 반복 수정이 이어지는 일을 제한하고, 남은 노트는 정답표 앞에 일반 표로 붙입니다.
- 검수자가 원본과 출력에서 선택지 행, 도형, 작은 기호를 대조하기 쉽게 관련 이미지를 함께 제공합니다.

## 도형

- 보기 상자 안 도형과 그림으로 된 선택지를 처리합니다.
- 도형 소스를 작업 폴더의 `.tex` 파일로 받아 렌더하므로 JSON 문자열 이스케이프 없이 수정할 수 있습니다.
- 배치 폭에 맞춰 좌표 크기를 조정하고 라벨 글자 크기는 본문과 같은 크기로 유지합니다.
- 선·점·호·다른 라벨과 겹친 라벨은 빈 공간으로 옮겨 읽기 쉽게 합니다. 원본의 가로세로 비율과 문제에 적힌 도형 조건을 비교해 눈에 띄는 차이를 알립니다.
- 한 쪽의 도형을 여러 개 함께 렌더해 대기 시간을 줄입니다.

## 수식과 작업 이어하기

- 프라임, 쉼표, 적분의 `dx`, 함수 이름과 인자, 행렬 칸의 간격을 한글 수식에 맞게 다듬었습니다.
- 출력과 도형 렌더는 짧은 응답 단위로 이어가며, 여러 작업이 한글 출력을 동시에 시도하면 차례를 기다립니다.
- 작업이 중단된 경우 남은 상태를 확인해 같은 job을 이어가거나 새 job을 만들도록 안내합니다. 끝난 작업의 잠금은 다음 실행에서 정리합니다.
- OpenCode가 일부 입력을 JSON 값으로 전달하는 경우에도 실제 전달된 내용을 보존하도록 처리했습니다.

## 설치 변경

새 프로그램이나 Python 패키지를 추가하지 않았습니다. 기존 v2.7.3을 쓰는 경우 스킬 폴더 전체를 v2.7.9로 교체하고, 사용 앱에서 `hwp-restoration` MCP를 다시 연결하세요. OpenCode 연결은 [설치 안내](../AGENT_INSTALL.md)를 참고하세요.
