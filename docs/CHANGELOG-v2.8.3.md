# v2.8.3 변경 내용

v2.8.2 이후의 변경입니다. 이번 버전에서 크게 세 가지가 바뀌었습니다.

- 작업 방식을 말로 고를 수 있습니다.
- 스킬 업데이트를 한마디로 요청할 수 있습니다.
- 도형 엔진의 각 표시 화살표 오류를 고쳤습니다.

아래 수치는 모두 실제로 잰 값입니다. 측정마다 몇 번 돌렸는지 함께 적었습니다.

## 1. 작업 방식을 말로 고르기

복원을 요청할 때 원하는 방식을 함께 말하면, 그 설정으로 작업합니다. 말하지 않은 항목은 기본값 그대로입니다.

| 무엇을 | 고를 수 있는 것 | 기본 | 이렇게 말하면 |
|---|---|---|---|
| 도형 | 다시 그리기 / 원본에서 잘라 붙이기 / 넣지 않기 | 다시 그리기 | "그림은 잘라 붙여", "그림 빼고" |
| 정답표 | 만듦 / 안 만듦 | 만듦 | "정답표는 빼줘" |
| 최종 검수 | 전체 / 정답·누락만 / 안 함 | 전체 | "검수 없이", "정답만 확인해" |
| 검수 실패 시 수정 | 0~3회 | 1회 | "수정은 하지 마" |
| 검수 노트 쪽 | 붙임 / 안 붙임 | 붙임 | "노트 쪽은 빼" |
| 머리말 | 학교·연도·시험 이름 | 파일 이름에서 추정 | "연도는 2024", "학교는 ○○고" |
| 묶음 | 빠른 / 균형 / 품질 | 없음 | "빠른 모드로" |
| 저장 위치 | 원본 폴더 / 지정 폴더 | 원본 폴더 | "결과는 D:\시험지에 저장" |

- **설정 알림**: 작업을 시작할 때 "이렇게 작업을 시작합니다."로 적용할 설정을 알리고, 승인을 기다리지 않고 바로 진행합니다. 바꾸고 싶으면 작업을 멈추고 다시 말하면 됩니다. "앞으로 시작 전에 확인받고 해"라고 하면 그다음부터는 "진행"이라고 할 때까지 기다립니다.
- **기본값 저장**: "앞으로 항상", "다음부터도"라고 말한 설정은 사용자 폴더의 `.hwp-restoration\preferences.json`에 저장되어 다음 작업부터 쓰입니다. 이 파일은 스킬 폴더 밖에 있어서 업데이트해도 지워지지 않습니다.
- **머리말 자동 채움**: 학교·연도·시험 이름을 파일 이름에서 추정해 머리말에 넣습니다. 파일 이름에 없는 칸은 `-`로 인쇄됩니다.
- **설정 안내**: "뭘 바꿀 수 있어?"처럼 물으면, 에이전트가 설정 안내 문서로 항목별 장단점을 설명합니다.

### 도형을 원본에서 잘라 붙이기

- 원본 PDF의 그림 부분을 300 dpi로 잘라 넣습니다. 모양은 원본과 똑같고, 다시 그리는 것보다 빠르고 쌉니다.
- **한계**: 그림 위의 연필 동그라미나 풀이 글씨도 같이 들어갑니다. 인쇄 잉크만큼 진한 필기는 걸러낼 방법이 없어서, 깨끗한 원본에만 권합니다. 필기가 그림 선을 덮은 도형만 다시 그립니다.
- **자르는 상자**: 상자 가장자리가 글자나 선을 자르면 엔진이 가까운 빈 줄까지 상자를 옮깁니다. 선택 패키지 OpenCV가 있으면, 제작자가 처음 잡은 상자를 도형에 맞춰 줍니다.
- **상자 수정 횟수**: 도형 수정 한도를 넘지 않습니다. 넘으면 마지막 상자를 그대로 씁니다.

**측정** (2쪽, 도형 6개, opencode muse, 설정마다 한 번씩)

| 도형 | 가중 토큰 | 시간 |
|---|---:|---:|
| 넣지 않기 | 0.47M | 5.1분 |
| 잘라 붙이기(가장자리 맞춤 포함, OpenCV 맞춤 전) | 0.70M | 8.1분 |
| 다시 그리기(기본) | 1.10M | 17.9분 |

### 빠른 모드

- 설정 내용: 그림 잘라 붙이기, 정답·누락만 검수, 수정 회차 없음, 노트 쪽 없음, 흑백 이미지입니다.
- 측정: Antigravity에서 위와 같은 2쪽을 한 번씩 돌렸습니다. 기본 설정은 13.2분, 5시간 한도 4.07%p였고, 빠른 모드는 9.2분, 1.65%p였습니다. 정답은 두 설정 모두 9개 중 9개 맞았습니다.
- 한계: 한 번 잰 값입니다. 필기가 많은 원본에서는 그림에 필기가 남습니다.

### 제작자·검수자 모델

- 제작자와 검수자의 모델을 메인과 같게, flash 급, flash lite 급 중에서 고를 수 있습니다. 기본은 메인과 같습니다.
- **flash lite 급 제작자는 권하지 않습니다.** 8쪽 시험지를 한 번씩 돌린 결과, 메인과 같은 모델로 돌렸을 때보다 모든 면에서 나빴습니다.
  - 시간: 28분 → 67분
  - 5시간 한도: 10.7%p → 12.3%p
  - 정답표: 7문항이 틀렸습니다.
  - 도형 검수 노트: 1쪽 → 10쪽

## 2. 스킬 업데이트

이제 다음처럼 말하면 에이전트가 스킬을 최신 공개 버전으로 업데이트합니다.

```text
hwp-exam-restoration 스킬 업데이트해줘
```

- **받는 곳**: 이 저장소의 최신 GitHub 릴리스만 받습니다. 바꾸기 전에 ZIP과 파일마다 해시를 확인합니다.
- **백업**: 스킬 폴더를 사용자 폴더의 `hwp-restoration-backups`에 백업합니다. 업데이트 도중 실패하면 그 백업으로 자동 복구합니다. 끝난 뒤에도 결과에 적힌 명령으로 이전 버전으로 되돌릴 수 있습니다.
- **그대로 두는 것**: `.mcp-venv`와 사용자가 넣은 파일은 그대로 둡니다. Python 패키지는 목록이 바뀐 경우에만 설치합니다.
- **Antigravity**: 서브에이전트 역할 정의도 함께 다시 설치하고, 스킬의 파일과 같은지 확인합니다.
- **업데이트한 뒤**: 앱에서 MCP를 재연결해야 새 코드가 실행됩니다. 에이전트가 그렇게 알려 줍니다.
- **v2.8.2 이하 사용자**: 그 버전에는 이 기능이 없습니다. README의 업데이트 요청문으로 v2.8.3까지 한 번 올리면, 다음부터는 위 한마디로 됩니다.

## 3. 도형 고친 점

- **각 값 화살표**: 화살 끝이 각 호의 가운데에 정확히 닿습니다.
  - 전에는 호가 기록된 반지름의 0.85배로 그려져서, 화살 끝이 호에 약 0.5 mm 못 미쳤습니다.
  - 제작자가 그림 전체에 `scale`을 주면 화살 끝이 호 안쪽이나 바깥쪽으로 밀렸습니다.
  - 호의 크기는 사용자가 승인한 크기 그대로입니다.
- **화살표 꼬리**: 오른쪽 위로 나가는 화살표의 꼬리가 도(°) 기호 위에서 시작하던 문제를 고쳤습니다.
- **제작자에게 알리는 경고**: 아래 경우에 제작자에게 한 줄씩 알려, 엔진이 그리는 방식으로 바꾸게 합니다. 원본과 같으면 그대로 둡니다.
  - 각의 값이나 구하는 각(x 등)을 화살표와 함께 손으로 그린 경우
  - 함수 그래프를 제어점으로 그린 경우
  - 길이 숫자가 해당 선분에서 3 mm 넘게 떨어진 경우
- **그래프 도구**: 그래프용 명령 `\ExamCurve`, `\ExamAxes`, `\ExamXLabel`이 생겼습니다. 다만 이 도구로 그래프가 나아졌는지는 확인되지 않았습니다. 블라인드 비교(18쌍) 결과는 도구 쪽 5, 이전 쪽 8, 비슷함 5였습니다.

## 4. 설치와 호환

- **업데이트 방법**: 스킬 폴더 전체를 v2.8.3으로 교체하고 `hwp-restoration` MCP를 다시 연결하세요. 첫 `hwp_prepare` 응답의 `runtime_version`이 `2.8.3`이어야 합니다.
- **필수 Python 패키지**: v2.8.2와 같습니다.
- **선택 패키지**: OpenCV(`opencv-python-headless`)는 새로 생긴 `requirements-optional.txt`에 있습니다. 필수 패키지를 설치한 뒤 따로 설치하며, 없어도 복원은 동작합니다.
- **Antigravity 역할 정의**: 4개(제작자·검수자의 flash 급, flash lite 급)가 늘어 모두 6개입니다. 설치 안내 3번대로 6개를 모두 설치하세요. 설치된 정의가 스킬의 파일과 다르면 엔진이 전용 타입 대신 일반 에이전트를 씁니다.
- **기존 작업**: 이전 버전으로 만든 작업 폴더와 HWP·HWPX 파일은 바뀌지 않습니다.

## 5. 알려진 한계

- 문제 풀이에 쓰는 선이 원본에 없는데도 도형에 그려지는 경우가 있습니다. 예를 들어 반지름이 같은 두 원의 공통현이 그렇습니다. 원본 스캔과 자동으로 대조하는 방법을 시험했지만 잘못 잡는 경우가 많아 넣지 않았습니다. 검수 노트와 결과물을 직접 확인하세요.
- 잘라 붙이기는 필기가 있는 원본에서 필기도 함께 옮깁니다.
- 빠른 모드와 잘라 붙이기의 수치는 2쪽짜리 시험지 하나로 잰 값입니다.
