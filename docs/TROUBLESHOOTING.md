# 문제가 생겼을 때

| 보이는 상황 | 에이전트에게 요청할 내용 |
|---|---|
| 스킬을 못 찾음 | “설치 위치를 확인하고 그 폴더의 SKILL.md를 읽어주세요.” |
| hwp-restoration 도구가 안 보임 | “MCP 등록 상태와 현재 앱의 연결을 확인해주세요. 필요한 재연결 방법을 알려주세요.” |
| runtime_version이 2.7.9가 아님 | “제작을 시작하지 말고 해당 MCP 서버를 재연결해주세요.” |
| Python이나 라이브러리 오류 | “전용 .mcp-venv와 requirements-mcp.txt를 확인하고, 실패한 항목만 알려주세요.” |
| 도형 렌더링 실패 | “TeX 실행 파일과 TikZ 설치 상태를 진단해주세요. 내부 코드를 수정하기 전에 환경 오류인지 확인해주세요.” |
| 한글 프로그램이 없다고 나옴 | 데스크톱 한컴오피스 한글이 필요합니다. 에이전트에게 공식 설치 조건을 안내받으세요. |
| 글꼴 대체, 겹침, 잘림 | “양식 글꼴과 실제 출력 페이지를 확인해주세요. 통과 처리하지 말고 해당 부분을 수정해주세요.” |
| 권한/보안 창이 나옴 | “현재 필요한 정상 권한을 설명해주세요.” 보안 기능을 통째로 끄거나 출처 불명의 모듈을 설치하지 않습니다. |
| 402, 선불 크레딧 소진 | API 결제 잔액 문제입니다. 작업을 보존하고 재시도를 멈춥니다. 사용자가 해결한 뒤 이어갑니다. |
| 정답표가 없음 | “기존 작업의 정답표 설정과 최종 출력 쪽을 확인해주세요.” 비용 비교용 테스트는 정답표를 끄기도 했지만 일반 복원은 기본 포함입니다. |
| 특정 도형·숫자가 틀림 | 문항 번호와 차이를 알려 해당 부분만 수정·재검수하도록 합니다. |
| 정답표 앞에 검수 노트 표가 있음 | 자동 검수가 넘긴 차이 목록입니다. 확인하고 고친 뒤 표 쪽은 지워도 됩니다. |
| `existing_hwp_session` | 직접 연 한글 창이 있으면 저장하고 닫은 뒤 다시 출력하도록 요청하세요. 엔진이 띄웠다가 남은 한글은 다음 출력이 자동으로 닫습니다. |
| `native_export_waiting_for_another_job` | 다른 시험지 작업이 한글로 출력하는 중입니다. 기다리면 이어서 진행합니다. |
| `native_export_queue_timeout` | 다른 작업들이 10분 넘게 한글을 쓰고 있었습니다. 몇 분 뒤 같은 출력 경로로 다시 빌드하도록 요청하세요. |
| 작업 도중 창을 닫았음 | 같은 PDF와 같은 결과 폴더로 다시 요청하세요. 남은 잠금과 한글 프로세스는 자동으로 정리됩니다. |

설치 에이전트가 파일을 읽을 수 없다면 [릴리스 ZIP](https://github.com/acb0808/hwp-exam-restoration/releases/tag/v2.7.9)을 직접 내려받아 압축을 푼 폴더 위치를 알려주세요.

오류 제보에는 버전, 사용 앱, 오류 문구와 재현 단계만 먼저 적으세요. API 키, 비밀번호, 전체 설정 파일, 학생 개인정보나 배포 권한이 없는 시험지를 공개 이슈에 올리지 마세요.
