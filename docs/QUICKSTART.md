# 처음부터 사용하기

## 1. 설치하기

[처음 설치하는 경우 README의 설치 요청문](../README.md)을 복사해 PC의 파일과 프로그램을 사용할 수 있는 AI 에이전트에게 보냅니다. v2.7.3 사용자라면 README의 **기존 사용자 업데이트 요청문**을 사용해 스킬 경로 중복을 정리합니다. 사용 중인 앱에 맞는 절차는 [AGENT_INSTALL.md](../AGENT_INSTALL.md)에 있습니다.

## 2. PDF와 저장 위치 알려주기

PDF를 첨부하거나 파일 경로를 말합니다. 결과 폴더도 함께 정하면 HWP와 PDF를 찾기 쉽습니다.

```text
이 수학 시험지를 hwp-exam-restoration 스킬로 복원해주세요.
문제 쪽의 본문·수식·선택지와 필요한 도형을 양식에 넣고,
마지막 쪽에 정답표를 만들어주세요.
읽기 어려운 부분은 추측하지 말고 문항과 위치를 알려주세요.
결과는 이 폴더에 저장해주세요: C:\내폴더\시험지결과
```

표지, 빈 면, 안내문, 해설과 기존 정답 페이지는 기본 복원 대상이 아닙니다. 어느 쪽을 문제 페이지로 쓸지 사용자가 매번 고를 필요는 없습니다.

## 3. 읽기 어려운 곳에 답하기

필기나 흐린 스캔이 인쇄 기호를 가린 경우 에이전트가 특정 문항만 질문할 수 있습니다. 확실히 아는 내용만 알려주세요. 모르면 확인할 수 없다고 답하면 추측 대신 미확인 상태로 남깁니다.

## 4. 결과 사용하기

HWP/HWPX는 한글에서 편집하고 PDF는 화면에서 확인하는 파일입니다. 남아 있는 검수 노트가 있으면 해당 문항과 도형을 확인한 뒤 한글에서 직접 수정할 수 있습니다.
