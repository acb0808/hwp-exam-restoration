# 처음부터 사용하기

## 1. 설치를 맡기기

[첫 화면](../README.md)의 설치 프롬프트를 복사해 PC를 조작할 수 있는 AI 에이전트에게 보냅니다. 에이전트가 준비물을 확인하고 설치합니다. 한글 프로그램이 없다면 먼저 설치해야 합니다. 한글 뷰어만으로는 복원 결과를 만들 수 없습니다.

에이전트가 “MCP 재연결이 필요하다”고 하면 사용 중인 앱에서 `hwp-restoration` 연결을 다시 켭니다. MCP는 **AI가 시험지를 만들 때 사용하는 로컬 도구 연결**이라고 생각하시면 됩니다.

## 2. 원본과 저장 위치 알려주기

PDF를 첨부하거나 파일 위치를 알려줍니다. 저장할 폴더도 함께 정하면 결과를 찾기 쉽습니다.

```text
이 PDF를 hwp-exam-restoration 스킬로 복원해주세요.
결과는 제가 지정한 결과 폴더에 저장해주세요.
문제와 수식, 필요한 도형을 넣고 마지막 페이지에 정답표를 만들어주세요.
스킬의 독립 검수 절차까지 완료해주세요.
```

이후 에이전트는 문제 쪽을 골라 페이지별로 제작하고, 한글 파일을 만든 뒤 별도 검수자가 원본과 비교합니다. 표지나 빈 면을 넣을지 일일이 선택할 필요는 없습니다. 기본 범위는 문제 쪽입니다.

## 3. 흐린 글자만 확인해주기

필기가 인쇄된 숫자를 완전히 가린 경우에는 에이전트가 문항 일부를 물어볼 수 있습니다. 아는 내용만 답해주세요. 알 수 없다면 “확인 불가”라고 알려 추측이 최종 시험지에 들어가지 않게 합니다.

## 4. 최종 결과 확인

HWP/HWPX는 편집용, PDF는 화면 확인용입니다. 배포 전에 PDF의 본문·수식·선지, 도형의 라벨·선·각도 표시, 마지막 정답표를 확인합니다. 자동 검수가 통과해도 오류가 남을 수 있습니다.

문제가 있으면 전체를 다시 만들도록 요청하기보다 위치를 알려주세요.

```text
기존 작업을 유지하고 20번 도형만 수정해주세요.
접힌 종이 안에 원본에는 없는 선이 보입니다.
수정한 뒤 재출력하고 해당 페이지를 같은 독립 검수자가 다시 확인해주세요.
```

## 검수 노트 표 읽기

정답표 바로 앞 쪽에 `쪽 | 문항 | 구분 | 검수 내용` 표가 붙을 수 있습니다. 자동 검수가 고치지 않고 넘긴 차이입니다. 대부분 도형의 세부 모양(음영, 보조선, 그림 속 무늬)이고, `미해결`로 적힌 것은 한 번 고친 뒤에도 남은 본문 차이입니다. 이 표를 보고 한글에서 직접 고치거나, 문항 번호를 알려 에이전트에게 수정을 요청하세요. 확인이 끝나면 표 쪽은 지워도 됩니다.

## 모델과 effort

현재 실전 검증 모델은 Gemini 3.8 Flash High(Antigravity)입니다. 다른 모델이나 다른 호스트에 같은 결과를 보장하지 않습니다.

## 여러 시험지를 동시에 할 때

에이전트 창을 여러 개 띄워 시험지마다 따로 요청해도 됩니다. 한글 출력은 PC에서 한 번에 하나만 되므로, 마지막 출력 단계에서 앞 작업이 끝나기를 기다렸다가 이어서 진행합니다(최대 10분). 동시에 여러 개를 돌리면 모델 사용량도 그만큼 함께 소모됩니다.

## 작업이 중단된 경우

결과 폴더와 기존 대화는 보존합니다. 같은 PDF와 같은 결과 폴더로 다시 요청하면 됩니다.

- 모든 쪽이 끝난 뒤 끊겼다면 이미 만든 쪽을 그대로 두고 한글 출력과 검수만 다시 합니다.
- 쪽 작업 도중에 끊겼다면 새 작업 폴더에서 처음부터 다시 합니다.
- 출력 도중 끊겨 화면에 보이지 않는 한글이 남아 있어도, 다음 출력이 그것을 닫고 진행합니다. 사용자가 직접 연 한글은 닫지 않습니다.

API 잔액 부족이면 충전 여부를 직접 결정하고, 해결 후 기존 대화에서 계속하도록 요청하세요. rewind로 오래된 작업 상태를 무작정 재사용하거나 결과 폴더를 삭제하지 마세요.
