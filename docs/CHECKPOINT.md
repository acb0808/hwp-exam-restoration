# v2.7.3 공개 체크포인트

기준일: 2026-09-27. 복원 런타임을 v2.7.3으로 고정한 배포입니다. 이후 문서 정비는 런타임을 새 버전으로 바꾼 것이 아닙니다.

공개 포장 과정에서 양식의 작성자 메타데이터를 익명화하고, 현재 코드와 어긋나 설치 진단을 막던 런타임 파일 해시 2개를 바로잡았습니다. 관련 무결성 매니페스트도 갱신했습니다. 복원 알고리즘과 모델 지침은 변경하지 않았습니다.

## 포함한 개선

- 페이지 전체를 먼저 작성하고 제출 시 수식·형식을 일괄 검사합니다.
- 별도 수식 사전 검사를 제거하고 반환된 오류만 수정합니다.
- 제작자가 MCP에 직접 제출하여 메인의 중계를 줄입니다.
- 불명확한 이미지 부분만 확대하며, 동시에 필요한 부분은 묶어 요청합니다.
- 도형 대조, 엄격한 수식 검사, 독립 최종 검수와 정답표 기능은 유지합니다.

## 실제 API 측정

동일한 4쪽·22문항 시험지, 도형 파일 4개, Gemini 3.8 Flash, 현재 Antigravity CLI에서 실행한 값입니다. 정답표는 구버전과 범위를 맞추기 위해 제외했습니다. 일반 사용자 복원의 기본값은 정답표 포함입니다.

| 버전/설정 | 비용 | 시간 | 상태 |
|---|---:|---:|---|
| v2.3.1 / High | $2.712826 | 857.501초 | 발견된 오류 수정·재검수 포함 |
| v2.7.3 / High | $1.917113 | 652.500초 | 발견된 오류 수정·재검수 포함 |
| v2.7.3 / Medium | 현재까지 $1.663516 | 553.407초 | API 잔액 소진으로 검수 도중 중단 |
| v2.7.3 / Low | 미측정 | 미실행 | 과금 없는 설정 확인만 완료 |

High 전체 비용은 이 표본에서 29.3% 낮았습니다. 그러나 첫 자동 완료 비용은 v2.3.1 $1.649606, v2.7.3 $1.639555로 거의 같았고, 절감액 대부분은 오류 수정 단계 차이였습니다. **기본 제작 비용이 항상 29.3% 줄어든다는 뜻이 아닙니다.** 각 조건 한 번의 관측이며 Antigravity 구독 한도로 환산할 수 없습니다.

비용은 실제 사용량에 동일 기준 단가(백만 토큰당 일반 입력 $0.75, 캐시 입력 $0.075, 출력·추론 $3.75)를 적용한 값이며 청구서 실결제액이 아닙니다. 외부 분석·시각 대조 비용은 제외했습니다.

CLI가 전송한 `thinkingBudget`은 Low 1000, Medium 4000, High -1(동적)이었습니다. 이는 Gemini API의 native `thinkingLevel`을 직접 지정한 비교가 아닙니다. [Google thinking 설명](https://ai.google.dev/gemini-api/docs/generate-content/thinking)

## 품질과 미완료 사항

High도 접힌 종이 안의 불필요한 점선을 첫 검수에서 놓쳤고, 추가 대조 후 수정했습니다. Medium 출력에는 각도 기호 누락과 가려진 원호 처리 오류가 관찰됐으나 검수·수정은 완료되지 않았습니다. 따라서 **최적 effort는 아직 미확정**입니다.

v2.7.3 개발 시 회귀 테스트 352개와 독립 코드 검토를 통과했습니다. 이는 모든 PC에서 한글 출력이 정상이라는 보장이 아닙니다. 배포물 자체의 검증 결과는 [배포 검증 기록](../VALIDATION.md)에 별도로 적습니다.

개인 시험지·복원 결과·원시 대화 DB·API 영수증·재개용 체크포인트는 공개하지 않습니다. 이 저장소의 체크포인트는 배포 코드와 비식별 요약입니다. 개발자의 로컬 작업 재개 데이터는 별도로 보존되어 있습니다.
