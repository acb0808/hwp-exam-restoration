# v2.7.9 공개 체크포인트

기준일: 2026-10-03. 공개판 v2.7.3 이후의 v2.7.4~v2.7.9 변경을 묶은 배포입니다. 복원 런타임 버전은 `2.7.9`입니다. 변경 전체는 [업데이트 내역](CHANGELOG-v2.7.9.md), 설치 요구 사항의 차이는 [의존성 변화](DEPENDENCIES.md)에 있습니다.

## 포함한 개선

- **검수 판정 세 단계:** 통과 / 노트 있는 통과 / 실패. 도형 차이와 경미한 차이는 수정 회차를 만들지 않고 정답표 앞 검수 노트 표에 남깁니다. 수정은 쪽마다 최대 1회입니다.
- **도형:** 그림 선지와 보기 상자 안 도형, 파일 기반 렌더(`workers/page-NNNN/ID.tex`), 라벨 크기 고정, 교점·접점 계산.
- **엔진이 재는 도형 검사(모델 호출 없음):** 겹친 라벨 자동 이동, 문제 글의 위치 조건 대조, 원본과의 가로세로 비율 비교, 접할 듯 말 듯한 선과 원 실측, TeX 경고.
- **수식 띄어쓰기:** 프라임, 쉼표, 적분 dx, 함수 인자, 행렬 칸.
- **여러 작업 동시 실행:** 한글 출력 대기열, 동시 컴파일 실패 시 재시도.
- **중단 후 재시작:** 남은 한글 프로세스·잠금 정리, 모든 쪽이 끝난 작업은 빌드부터 이어서 진행.
- **응답 줄이기:** 긴 도구 응답을 파일로 돌리는 호스트에 맞춰 렌더 응답과 도형 규칙을 줄였습니다.
- **응답 시간 상한:** 렌더와 한글 출력을 기다리는 MCP 응답이 30초를 넘지 않습니다. 넘으면 진행 중이라고 답하고 다음 호출이 결과를 받아 갑니다(opencode는 60초가 지나면 연결을 끊습니다).

**Antigravity 한도 가이드라인 (Gemini 3.8 Flash High, 5시간 한도)**

실측: 시험지 11종을 13번 복원했습니다(혼자 3회, 2개 동시 1회, 5개 동시 1회, 3개 동시 1회). 함께 돌린 실행은 합계 한도를 각 시험지의 모델 호출 수로 나눴습니다. 모델 호출 1회당 한도는 0.092~0.108%로 실행마다 거의 같았습니다.

| 시험지 | 실측 (시험지 수) | 한 개당 |
|---|---|---:|
| 고등학교 4쪽, 도형 4개 이하 | 7.5~8.2% (4) | **약 8%** |
| 고등학교 5~6쪽, 도형 5개 이하 | 9.4~11.8% (5) | **약 11%** |
| 중학교 6쪽, 도형 6개 | 12.2% (1) | **약 12%** |
| 중학교 6쪽, 도형 18개 | 15~17% (1종 3회) | **약 16%** |

- **어림식:** 한도(%) ≈ 1.7 × 문제 쪽 수 + 0.33 × 도형 수. 실측 13회와의 차이는 중앙값 0.6%p, 최대 1.5%p였습니다.
- **5시간 창 하나(100%)로:** 고등학교 4쪽 시험지 약 12개, 고등학교 6쪽 약 9개, 도형이 많은 중학교 시험지 약 6개.
- **동시 실행은 한도를 늘리지도 줄이지도 않습니다.** 시험지 하나에 드는 한도는 같고, 시간만 줄어듭니다. 5개를 동시에 돌리면 11.5분, 3개는 12.6분에 모두 끝났습니다.
- **여유를 두세요.** 같은 시험지도 실행마다 ±2%p 정도 흔들리고, 검수에서 반려되면 그 쪽을 다시 만들어 2~4%p가 더 듭니다. 남은 한도가 (예상 합계 + 10%)보다 적으면 개수를 줄이기를 권합니다. 도중에 한도가 떨어지면 쪽 작업이 끊겨 처음부터 다시 해야 할 수 있습니다.
- 이 값은 v2.7.9와 Gemini 3.8 Flash High 기준입니다. 다른 모델이나 effort에서는 다시 재야 합니다.

## 품질과 남은 한계

- 엔진 검사는 일부 오류만 잡습니다. 지난 도형으로 맞춘 결과, 문제 글 조건 경고 13건과 기하 실측 경고 4건은 모두 실제 어긋남이었고, 비율 경고는 잰 도형의 약 3%가 오탐이었습니다. 놓치는 오류도 있습니다.
- 도형의 세부 모양(음영 범위, 보조선, 그림 속 무늬)은 원본과 다를 수 있고, 이런 차이는 수정하지 않고 검수 노트로 남깁니다. **검수 노트 표를 꼭 확인하세요.**
- 검수자가 작은 기호를 확대하지 않고 노트로 넘기는 경우가 있습니다.
- 제작자가 엔진 경고 없이 같은 도형을 여러 번 다시 그리는 경우가 있습니다(실측 두 번, 각각 7번).
- 여러 작업 동시 실행은 opencode로 5개(시험지 22개), Antigravity로 5개까지 확인했습니다.
- 쪽 작업 도중에 끊긴 작업은 처음부터 다시 합니다.
- 출력 HWPX의 마지막 저장자 메타데이터에는 한글이 저장할 때 쓴 PC 계정명이 들어갑니다.

배포물 자체의 검증은 [배포 검증 기록](../VALIDATION.md)에 따로 적습니다.
