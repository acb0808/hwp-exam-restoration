# 한 쪽 전사용 Markdown

`reading.md`에는 원본 문제 쪽의 왼쪽/오른쪽 단·문항 순서·선택지 행별 개수를 보존한다. 본문 줄바꿈·개체 좌표와 최종 배치는 엔진이 맡지만 **선택지 행 구분은 합치지 않는다**. 실제 인쇄된 문제 번호·조건·수식·보기·선지·배점을 보존한다. 원본 머리말·꼬리말·쪽번호·저작권·필기는 제외한다. 페이지·담당자·원본 정보, JSON·해시·폰트·좌표 파일은 작성하지 않는다.

제출 전 3초 점검: `$$...$$`는 빈 줄 사이 독립 한 줄, LaTeX 명령은 `$...$` 안, 문장 속 네모는 `[[box:(가)]]`.

```markdown
## left
### q1
1. $x-1$의 값은? [3점]

::: box 보기
ㄱ. $x>0$

ㄴ. $x<3$
:::

::: choices 3
① $-1$ | ② $0$ | ③ $1$
④ $2$ | ⑤ $3$
:::

![](figure:q1-figure-1)

## right
### q2
2. 다음 식을 간단히 하시오.

$$x+x$$
```

- `## left`/`## right`는 원본 단이다. 문항 앞에 반드시 적고 원본에 있는 단만 사용한다. `### q1`은 식별자이며 인쇄된 번호 `1.`도 본문에 적는다.
- 흐리거나 잘려 확인할 수 없으면 해당 문항을 `### q2 ?`로 표시하고 이유를 보고한다. 한 쪽이 불완전하면 `<!-- incomplete: 아래쪽 잘림 -->`을 추가한다. 추측해 채운 뒤 완료로 제출하지 않는다.
- 새 전사의 수식은 문장 안 `$LaTeX$`를 기본으로 한다. `$$LaTeX$$`는 예시처럼 앞뒤 빈 줄이 있는 독립 문단의 한 줄에만 쓴다. 여러 줄 `$$`는 지원하지 않는다. 역슬래시를 JSON처럼 이중으로 쓰거나 부호·괄호를 추정해 바꾸지 않는다.
- 수식 명령은 `$...$` 안에만 둔다. 집합 조건의 막대는 `$x | x>0$`처럼 `|`로 쓴다(`\mid`는 미지원). 빈집합은 `\emptyset` 또는 `\varnothing`을 지원한다. `\quad` 같은 간격 명령은 근사 변환으로 거부되므로 임의 삭제·치환하지 않는다. 독립된 두 수식 사이의 본문 공백이면 `$p:x=1$ $q:x=2$`처럼 나눈다. 제출 전에 각 `$$...$$`가 독립된 한 줄 문단인지 확인한다.
- 한글 설명은 `$A=\{x | x\le100,\text{ 자연수}\}$`처럼 쓴다. `\text{...}` 안에 수학 명령을 넣지 않는다. 생략점 `$a_1+\cdots+a_n$`, 선분 `$\overline{AB}$`, 호 `$\overparen{AB}$`, 각 `$\angle ABC=30^\circ$`, 단위 `$4 \mathrm{cm}$`, 평행 `$\overline{AB} \parallel \overline{CD}$`, 아래첨자 `$A_k(a)$`를 지원한다. `\widehat{AB}`는 모자(^) 기호라서 호·각에 쓰지 않는다. 이 예시로 전체 원고를 먼저 작성해 제출한다. 제출이 모든 수식을 검사하므로 별도 사전 검사를 하지 않는다. 반환된 오류 설명으로 해결되지 않을 때만 `hwp_help(topic="equations")`의 예시를 참고한다.
- 빈 줄은 문단 경계다. 같은 문단의 줄바꿈은 보존되므로 보기 좋게 임의로 줄을 접지 않는다.
- `::: box 제목` … `:::`는 보기상자다. 제목은 생략할 수 있다. 내부는 일반 문단과 독립 줄 도형 표시(`![](figure:q3-box)`)만 가능하며 상자 중첩은 불가하다. 원본 보기상자 안의 그림은 상자 안에 둔다. `> 본문`도 무제목 상자다.
- 문장 속 작은 직사각형 빈칸은 `[[box:(가)]]`처럼 적는다. 예: `[[box:(가)]]에 알맞은 수는?` 테두리와 안의 글자는 한글에서 편집 가능하며, 수식 `$...$` 안에는 넣지 않는다.
- `::: choices N`의 N은 원본 한 줄 최대 선택지 수(1~5)다. 위 예시는 원본이 3개+2개인 경우다. **선택지가 총 5개라는 이유로 N=5를 쓰지 않는다.** 원본이 한 줄 5개일 때만 5를 쓴다. 원본의 행마다 한 줄을 적고 수식 **밖**의 ` | `로 선택지를 나눈다. `$|x|$` 안의 막대는 구분자가 아니다. 빈 선택지는 불가하다.
- 도형은 문항 안에서 **세로로 쌓이며** 문항 칸의 높이는 정해져 있다. 원본에서 좌우로 나란히 놓인 그림(예: [그림2]의 두 패널, ⇨로 이어진 전후 그림)은 도형 하나로 그린다.
- `![](figure:q1-figure-1)`은 독립된 한 줄의 도형 자리다. 실제 도형의 TeX는 같은 담당자가 별도 파일에 쓰며 외부 이미지 링크는 쓰지 않는다.
- **선지가 그림인 문항**(예: 그래프 ①~⑤)은 선지 칸에 도형을 넣을 수 없다. 발문 아래 독립 줄 `![](figure:q5-choices)` 하나를 두고, 그 TikZ 한 장에 ①~⑤ 번호와 각 그림을 원본의 행 배치(예: 3+2)대로 함께 그린다. 이때 `::: choices` 블록은 쓰지 않는다(번호만 적은 선지 블록도 불가). 선지가 글·수식이면 기존처럼 `::: choices`를 쓴다.
- 본문의 별표·백틱·구분용 세로선은 백슬래시로 이스케이프한다. Markdown 강조·표·링크·HTML·코드블록과 통화 기호는 지원하지 않는다.

정답 작성 여부는 task.md 맨 위의 include_answers를 따른다. true인 작업에만 이어지는 정답 블록 형식을 적용한다. 파서가 줄 번호와 함께 오류를 돌려주면 보고된 부분만 고친다. 형식 통과는 원본 일치나 최종 출력 검수 통과를 뜻하지 않는다.
