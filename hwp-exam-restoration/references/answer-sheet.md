# 마지막 정답표용 답 블록

`reading.md`의 **모든 `###` 문항 본문 끝, 다음 문항 앞**에 블록 하나를 적는다. 엔진이 이 답을 모아 마지막 정답표 한 쪽을 만든다. 근거는 검수 자료이며 표에 인쇄되지 않는다. 별도 정답 파일·JSON·정답 에이전트는 만들지 않는다.

```markdown
::: answer
번호: 1
정답: ② $2$
근거: $1+1=2$이며 두 번째 선택지와 일치한다.
:::
```

`번호`, `정답`, `근거`는 각각 한 줄이다. 번호는 실제 인쇄 번호를 쓰고 `논술형 1`처럼 유형도 보존한다. 객관식 정답은 ①~⑤ 선지 번호로 시작하며 값과의 대응을 확인한다. 서답형은 같은 정답 줄에 모든 소문항 번호·값·단위를 구분해 적는다. 수식은 `$LaTeX$`로 쓴다.

이미 읽은 원본 조건·도형으로 계산하고 대입·역산 등 짧은 검산 근거를 남긴다. 공식 답이 제공되면 출처와 현재 문항의 대응을 확인한다. 학생 필기·채점 흔적은 근거가 아니다. 본문이나 도형 해석을 고치면 답도 다시 확인한다. 조건 부족·복수 답·판독 불확실성이 남으면 추측한 정답을 제출하지 말고 해당 문항을 보고한다.
