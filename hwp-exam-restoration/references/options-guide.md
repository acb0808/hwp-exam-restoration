# 설정 안내 (사용자에게 설명할 때 쓰는 문서)

사용자가 "설정 안내해줘", "뭘 바꿀 수 있어?", "검수는 어떻게 바꿔?"처럼 물으면 이 문서로 답한다. 표를 통째로 붙이지 말고 물어본 항목 위주로, 바꾸면 무엇이 좋아지고 무엇을 잃는지 함께 짧게 설명한다. 사용자의 말을 옵션으로 옮겨 `hwp_prepare`의 `options`에 넣는다(아래 "옵션 키"). 작업은 시작할 때 "이렇게 작업을 시작합니다."로 설정을 알리고 바로 진행한다. 사용자가 그 설정을 보고 작업을 멈춘 뒤 다시 지시하면, 제작자가 아직 배정되지 않았으면 같은 작업에 새 설정을 적용하고, 이미 배정됐으면 응답의 `restart_job`으로 새 작업을 시작한다(앞서 한 쪽은 다시 만든다).

## 한눈에 보기

| 무엇을 | 고를 수 있는 것 | 기본 | 이렇게 말하면 |
|---|---|---|---|
| 도형 | 다시 그리기 / 원본에서 잘라 붙이기 / 넣지 않기 | 다시 그리기 | "그림은 잘라 붙여", "그림 빼고" |
| 정답표 | 만듦 / 안 만듦 | 만듦 | "정답표는 빼줘" |
| 최종 검수 | 전체 / 정답·누락만 / 안 함 | 전체 | "검수 없이", "정답만 확인해" |
| 검수 실패 시 수정 | 0~3회 | 1회 | "수정은 하지 마" |
| 검수 노트 쪽 | 붙임 / 안 붙임 | 붙임 | "노트 쪽은 빼" |
| 모델 | 메인과 같음 / flash 급 / flash lite 급 | 메인과 같음 | "제작자는 flash로" |
| 머리말 | 학교·연도·시험 이름 | 파일 이름에서 추정 | "연도는 2024", "학교는 ○○고" |
| 묶음 | 빠른 / 균형 / 품질 | 없음 | "빠른 모드로" |
| 저장 | 원본 폴더 / 지정 폴더 | 원본 폴더 | "결과는 D:\\시험지에 저장" |
| 시작 전 확인 | 알리고 바로 진행 / 확인받고 진행 | 알리고 바로 진행 | "앞으로 시작 전에 확인받고 해" |

## 항목별 설명

**도형** (`figures`)
- 다시 그리기 `restore`: 도형을 깨끗한 그림으로 새로 그린다. 품질이 가장 좋고, 필기가 걸친 시험지도 깨끗하게 나온다. 시간과 비용이 가장 많이 든다.
- 잘라 붙이기 `crop`: 원본의 그림 부분을 그대로 잘라 넣는다. 빠르고 싸며 모양이 원본과 똑같다. 다만 그림 위의 연필 동그라미·풀이 글씨도 같이 들어간다. 깨끗한 원본에 권한다. 필기가 그림 선을 덮은 도형만 다시 그린다.
- 넣지 않기 `off`: 글과 수식만 옮긴다. 가장 빠르다. 그림이 있어야 푸는 문제는 출력만 보고 풀 수 없다.
- 세부 조정: 도형당 수정 횟수 `figure_fix_limit`(0~2, 기본 2). 다시 그리다 끝내 안 맞는 도형을 원본 그림으로 바꿔 넣을지 `figure_fallback`(`note` 노트에 적기 / `crop` 원본으로 대체). 제작자 스스로 하는 도형 대조를 끌지 `figure_check`(끄면 빨라지지만 그림 오류를 덜 잡는다). 선 굵기 `figure_line_width`(pt, 기본 0.3)와 라벨 크기 `figure_label_scale`(기본 0.85).

**정답표** (`answers`): `off`면 문제만 만들고 정답 계산과 정답표를 생략한다. 정답 검산도 하지 않는다.

**최종 검수** (`review`)
- 전체 `full`: 제작에 참여하지 않은 검수자가 모든 문항을 원본과 한 줄씩 대조한다. 가장 정확하다.
- 정답·누락만 `answers`: 빠진 문항, 답을 바꾸는 오독, 정답표만 본다. 문구의 작은 차이나 도형은 보지 않는다.
- 안 함 `off`: 검수자를 만들지 않는다. 가장 빠르지만 오류를 사람이 직접 확인해야 한다. 결과 보고에 "독립 검수를 하지 않음"이 표시된다.
- 수정 회차 `repair_rounds`(0~3, 기본 1): 검수에서 실패한 쪽을 몇 번 고칠지. 0이면 고치지 않고 남은 문제를 검수 노트로 넘긴다.
- 검수 노트 쪽 `review_notes_page`: `off`면 사람이 볼 항목을 문서에 쪽으로 붙이지 않고 결과 보고에만 적는다(출력 1회 절약).

**모델** (`reader_model` 제작자, `reviewer_model` 검수자): `inherit` 메인과 같음, `standard` flash 급, `light` flash lite 급. 가벼운 모델은 싸 보이지만, 측정(8쪽)에서 flash lite 제작자는 시간이 2.4배였고 할당량을 더 썼으며 정답이 7개 틀렸다. 깨끗하고 그림이 적은 쪽에만 권한다.

**머리말** (`metadata`: `school`, `year`, `exam_title`, `title`): 엔진이 파일 이름에서 학교·연도·시험을 추정한다(예: `[2024년 기출] 예시고 1-2 중간.pdf`). 표지는 읽지 않는다. 파일 이름에 없는 칸은 `-`로 인쇄되므로 처음 요청할 때 함께 말하거나, 시작 보고를 보고 멈춘 뒤 알려 주면 넣는다.

**묶음** (`preset`): 여러 설정을 한 번에 바꾼다. 묶음과 함께 말한 항목은 묶음보다 우선한다.
- 빠른 `fast`: 그림 잘라 붙이기, 정답·누락만 검수, 수정 회차 없음, 노트 쪽 없음, 흑백 이미지. 2쪽 시험지 실측(Antigravity)에서 기본 대비 할당량 −59%(4.07 → 1.65%p), 시간 −30%(13.2 → 9.2분), 정답은 같았다. 필기가 많은 원본은 그림에 필기가 남는다.
- 균형 `balanced`: 도형 수정 1회로 줄이고 나머지는 기본.
- 품질 `quality`: 기본에 검수자 확대 조각까지 켠다.

**그 밖**: 흑백 16단계 이미지 `image_mode: gray16`(이미지 비용 절약, 화질은 거의 같음). 제작자 확대 조각 `source_tiles`(끄면 싸지만 작은 기호 오독이 늘 수 있음). 결과 폴더 `output_dir`(절대 경로). 시작 전 확인 `confirm_settings`(기본 `off`: 설정을 알리고 바로 진행, `on`: 설정을 보여 주고 "진행"을 기다림).

## 기본값으로 저장하기

사용자가 "앞으로 항상", "다음부터도"라고 하면 그 설정을 `save_as_default:true`와 함께 넘긴다. 사용자 폴더의 `.hwp-restoration\preferences.json`에 저장되고 다음 작업부터 자동으로 쓰인다. 이번 요청에서 말한 것이 저장된 기본값보다 우선한다. 원래대로 돌리려면 기본값을 다시 저장하거나(예: `{"review":"full"}`) 그 파일을 지우면 된다.

## 옵션 키 (메인용)

`figures` restore/crop/off · `figure_fallback` note/crop · `figure_check` on/off · `figure_fix_limit` 0–2 · `answers` on/off · `review` full/answers/off · `repair_rounds` 0–3 · `review_notes_page` on/off · `reader_model`/`reviewer_model` inherit/standard/light · `preset` fast/balanced/quality · `figure_line_width` 0.2–0.6 · `figure_label_scale` 0.6–1.2 · `image_mode` color/gray16 · `source_tiles`/`review_tiles` on/off · `dpi` 72–600 · `metadata` {school,year,exam_title,title} · `output_dir` 절대 경로 · `confirm_settings` on/off
