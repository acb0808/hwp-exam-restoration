# 도형 작성과 검수

쪽 담당자가 원본의 점·선·곡선·라벨·인쇄 표식을 FIGURE_ID.tex로 복원한다. 스캔 crop·includegraphics·풀이·원본에 없는 보조선/표식은 금지한다.

그림 하나의 tikzpicture만 작성하면 엔진이 문서를 포장한다. 아래 짧은 명령은 이 조각 형식에서 쓴다. 기존 완결 TeX는 그대로 지원하지만 새 명령을 자동 주입하지 않는다.

```tex
\begin{tikzpicture}
% 관찰한 도형만 작성
\end{tikzpicture}
```

kotex·amsmath·calc·arrows.meta·angles·quotes·intersections를 쓸 수 있다. 좌표 → 선·음영 → 라벨·표식 순으로 작성한다. 라벨 수정 때문에 점 좌표·연결을 바꾸지 않는다.

**선·원 위의 점은 눈대중으로 적지 않고 계산한다.** 중점은 `($(A)!0.5!(B)$)`, 수선의 발은 `($(A)!(C)!(B)$)`, 원 위의 점은 `($(O)+(70:2)$)`처럼 쓴다. 두 선 또는 선과 원의 교점·접점은 이름 붙인 경로에서 구한다.

```tex
\draw[name path=circ] (8.4,1) circle (1);
\path[name path=fold] (6.6,0) -- (8.6,2);
\path[name intersections={of=circ and fold, by={Q,P}, sort by=fold}];
\draw[dotted] (6.6,0) -- (Q);  \draw (Q) -- (P);
```

`sort by=직선 경로 이름`을 넣어야 교점 이름이 그 직선을 따라가는 순서로 붙는다(없으면 원을 따라가는 순서라 뒤바뀔 수 있다). 이름 붙인 경로는 **실제로 원을 가로질러야** 교점이 생긴다. 보이는 선과 따로, 교점용 경로는 `($(A)!-0.5!(B)$) -- ($(A)!1.5!(B)$)`처럼 양쪽으로 넉넉히 늘린다(엔진이 `name path`만 있는 `\path`를 그림 크기 계산에서 빼므로 늘려도 여백이 생기지 않는다). 교점이 없으면 `No shape named intersection-1` 오류가 난다.

엔진은 좌표만 확대·축소해 그림을 width_mm에 맞추고 라벨은 본문 글자 크기로 둔다. 좌표 단위는 자유롭게 쓰되 라벨 글꼴 크기를 따로 키우거나 줄이지 않는다.

렌더 뒤 엔진이 PDF에서 라벨 글자를 재서, 선·호·점 표식·다른 라벨과 겹친 라벨을 4mm 안의 가장 가까운 빈자리로 옮기고 한 번 더 렌더한다. 자기 점보다 다른 점에 가까워지는 자리와, 겹치지 않던 선을 넘어가는 자리(각 안의 라벨이 각 밖으로 나가는 경우)로는 옮기지 않는다. `·`, `×` 같은 기호만 있는 노드, 테두리가 있는 글자, 15mm가 넘는 글은 옮기지 않는다. `\ExamLengthArc`의 흰 바탕 숫자는 자기 점선 호 위에 그대로 두고, 실선을 가릴 때만 옮긴다. 따라서 라벨이 조금 겹친다는 이유만으로 TeX를 고치지 않는다. 옮기고도 라벨끼리 겹쳐 읽을 수 없는 경우만 경고로 온다. 선 위에 남은 라벨은 알리지 않는다(원본도 좁은 각 안의 값이나 점선 호 위의 길이는 그렇게 인쇄한다).

원본에서 좌우로 나란히 놓인 그림은 한 tikzpicture에 함께 그린다. 도형은 문항 칸 안에서 세로로 쌓이므로 나누면 쪽이 넘친다. 렌더 응답의 `layout_warnings`는 한 문항의 도형 높이 합이 칸의 70% 이상임을 알린다.

렌더 응답의 `figure_warnings`는 원 근처에 있지만 원 위에 있지 않은 점, 헤더 목록과 다른 라벨, 그리고 렌더 PDF에서 잰 살짝 어긋남(접할 듯 접하지 않는 선, 닿을 듯 닿지 않는 선 끝, 접할 듯한 두 원)을 알린다. 엔진이 옮기고도 서로 겹친 라벨과, 문제 글의 위치 조건과 어긋난 점(`글의 조건 "BC의 중점 M": 그림에서 2.0mm 어긋남`)도 여기에 온다. 글의 조건은 TikZ 점 이름으로 대조하므로 글에 나온 점은 같은 이름으로 둔다(`O'`은 `Op`). 이름이 없으면 라벨 옆의 꼭짓점·교점으로 찾고, 불분명하면 검사하지 않는다. 원본 그림은 축척대로가 아닐 때가 많으므로, 길이·각 조건(같은 길이, 중점, 수선의 발, 직각, 평행)은 `원본도 그렇게 그려졌으면 그대로 둔다`가 붙어 한 번만 알리고 검수 노트로 남기지 않는다. 위치 조건(원 위, 접함, 교점, 선 위, 지름)은 원본에서도 보이므로 고칠 때까지 노트로 남는다. 원본 crop과 렌더에서 주된 도형(가장 큰 연결된 선 묶음)의 가로:세로가 1.25배 넘게 다르면 `비율: 원본 그림은 가로:세로 1.00:1, 렌더는 1:1.33`도 한 번 알린다. 글의 수치대로 그려서 달라진 것이면 그대로 두고, 아니면 원본 모양을 따른다. 실측 경고는 도형마다 처음 한 번만 오고, 다시 렌더해도 남은 어긋남은 검수 노트에 기록된다. 경고가 붙은 도형은 원본과 다시 대조해 계산으로 고치거나, 원본도 그렇다면 그대로 둔다.

**재사용 골격:** 원본과 점·연결 관계가 맞을 때만 그림당 `\ExamTemplate{종류}{옵션}` 하나를 쓴다. 맞지 않으면 일반 TikZ로 작성한다. 파일 탐색·추가 도구 호출은 없다.

| 종류 | 고정 구조 / 내부 좌표 순서 | 옵션 기본값(cm, 각도는 도) |
| --- | --- | --- |
| triangle | 삼각형 A(위), B(왼쪽 아래), C(오른쪽 아래) | base=4,height=3,apex=.5 |
| triangle-height | 위 구조와 수선 AH / A,B,C,H | base=4,height=3,apex=.5 |
| right-midpoints | C에서 직각인 ABC, D=BC 중점, E=AC 중점, O=AB 중점, OD·OE / A,B,C,D,E,O | base=4,height=3 |
| circle-triangle | 원과 내접삼각형 ABP, 중심 O / O,A,B,P | radius=2,a=220,b=320,p=90 |

apex는 밑변에서 꼭짓점의 가로 비율이다. 크기는 관찰한 비율에 맞춘다. 직각·등변·길이·음영은 자동 추가하지 않는다. 원본에 있으면 아래 명령이나 TikZ로 덧붙인다. `labels=A/B/C/D`처럼 순서대로 이름을 바꿀 수 있으며, 인쇄되지 않은 이름만 `-`로 숨긴다. **출력 이름을 바꿔도 내부 좌표 H 등은 그대로다.** 이름은 영문 한 글자와 선택적 아래첨자(`A_12`)를 지원한다.

골격 라벨은 도형을 움직이지 않고 8방향의 가까운 후보에서 선·점·다른 라벨을 피하며 자기 점과 가장 가깝게 배치한다. 원본의 방향이 중요하면 `posA=above`처럼 고정한다(above/right/below/left와 above-right 등 대각선). 겹침·연결 혼동이 해결되지 않으면 오류로 보고한다. **추정 글자 크기에 기반한 제한적 배치**이며, 나중에 덧붙인 선·음영·표식은 계산에 포함되지 않는다. 실제 렌더 대조는 그대로 한다. 골격 사용 시 그림/scope의 옵션·변환은 쓰지 않고 크기 매개변수로 조정한다.

**반복 표식:** 좌표 이름의 괄호는 생략한다. 원본에서 확인한 직각·길이 곡선은 아래 명령을 우선 사용하고 원본에 없는 표식은 추가하지 않는다.

| 용도 | 짧은 명령 | 조정 |
| --- | --- | --- |
| 직각(B가 꼭짓점) | `\ExamRightAngle{A}{B}{C}` | `[angle radius=1.6mm]`, 기본 2mm |
| 곡선 길이 | `\ExamLengthArc{A}{B}{$x$}` | 기본 점선·bend left=18·화살촉 없음; `[bend right=18,solid]` 등 |
| 개별 라벨 | `\ExamLabel[above right]{A}{$A$}` | anchor·xshift·yshift 조정; 겹치면 렌더 뒤 엔진이 옮긴다 |
| 등변 표식 1~3개 | `\ExamTicks{A}{B}{2}` | 선분 중앙·방향 자동 계산, `[rotate=15]` 조정; AB선은 별도로 그림 |
| 속 빈 화살표 ⇨ (그림 사이) | `\ExamImplies{4.7,1}` | `[minimum height=9mm]`, `[rotate=-90]`; ⇨ 글자는 TeX 글꼴에 없어 렌더가 실패한다 |

**인쇄 품질:**
- 라벨은 연결 대상이 분명한 빈 공간에 anchor·xshift·yshift로 배치한다. 선·곡선·다른 글자와 닿지 않게 한다. 좁은 각 안에 숫자를 억지로 넣거나 흰 배경으로 도형선을 지우지 않는다.
- 직각을 변 길이의 20% 같은 비율로 크게 만들지 않는다. 최종 인쇄에서 표식 한 변 약 1~1.8mm를 출발점으로 원본 비율에 맞춘다. scale·삽입 폭에 따라 실제 크기가 달라지므로 고정 수치만으로 통과하지 않는다.
- 길이 표시의 곡선/직선·점선·화살촉 유무를 원본대로 보존한다. 굽힘 방향·깊이는 원본에 맞추고 라벨과 분리한다. 숫자의 흰 틈은 길이 표시 위에만 두며, 원본에 없는 `<->`를 넣지 않는다.

수식 라벨은 TeX로 쓴다. 도형마다 배정 폴더에 `ID.tex`를 쓰고 첫 줄에 `% width_mm=NN source_bbox_px=왼쪽,위,폭,높이 labels=A,B,P,8,60°`를 적은 뒤(labels는 **그리기 전에 원본만 보고** 도형 안에 인쇄된 이름·숫자·캡션을 모두 적는다) `hwp_render_figures(job,page)`로 쪽 전체를 한 배치로 렌더한다. 고칠 때는 그 파일만 부분 수정하고 같은 호출을 반복한다. 오류·검수 지적만 수정한다. 명령 실행·환경 탐색·별도 렌더러·성공 도형의 시험 렌더는 없다.

review_tasks에 `compare_image`(왼쪽 원본 crop, 오른쪽 렌더)가 있으면 그 한 장으로 원본과 대조하고, 없으면 render_image만 원본과 대조한다. compare_image_error가 있으면 bbox를 고쳐 다시 렌더하지 말고 render_image와 이미 본 원본으로 검수한다. 자기 문맥에 보이는 원본은 재열람하지 않고 사라졌거나 불명확할 때만 확인한다. 전 도형 crop·저해상도 합본은 금지한다. 엔진이 재사용한 통과 항목은 다시 검수하지 않는다. 미검수 항목의 checks:

- geometry: 원본의 각 점에서 뻗는 실선·점선을 끝점까지 하나씩 따라 렌더에서 대응을 확인한다. 닮은 좌우·여러 수선도 생략하지 않는다. 교차·상대 위치·지름·밑변·닫힌 경계와 라벨에 가린 선도 확인한다.
- labels: 이름·숫자·수식·대상이 맞고 겹침·잘림이 없다.
- marks: 원본의 모든 직각 표시 위치를 먼저 대응한 뒤 크기를 본다. 길이 표시의 양 끝점·곡선/직선·선 종류·화살촉, 등변·각·음영을 각각 대응한다.
- source_comparison: 자기 문맥에서 실제 확인 가능한 원본과 해당 렌더를 대조했다. 기억만으로 판정하지 않는다.

수정한 그림은 지적 부분과 함께 그 그림 전체의 연결·표식을 다시 대조한다. 이미 열어 본 원본·렌더 안에서 수행하며 별도 목록 파일·추가 도구 호출은 만들지 않는다. 관찰·issues를 메인에게 보고한다. 렌더 성공만으로 통과하지 않는다. 엔진이 삽입하고 최종 검수자가 인쇄 크기의 가독성·겹침·표식을 대조한다.
