# 시험지 HWP 복원 스킬

스캔한 **한국어 수학 시험지 PDF**를 편집 가능한 **한글 HWP/HWPX**로 복원하는 AI 에이전트용 스킬입니다. 문제와 수식, 필요한 도형을 시험지 양식에 넣고 마지막에 정답표를 만듭니다.

**코드를 직접 작성할 필요는 없습니다.** 아래 설치 프롬프트를 PC의 파일과 도구를 사용할 수 있는 AI 에이전트에게 보내세요. 이 파일 자체가 실행 프로그램은 아닙니다.

현재 공개 버전: **v2.7.9 · 2026-10-03 체크포인트**. Windows의 Antigravity CLI(Gemini 3.8 Flash High)와 opencode에서 로컬 MCP로 검증했습니다. 다른 에이전트의 자동 호환은 보장하지 않습니다.

## v2.7.3에서 달라진 점

- **검수:** 사소한 차이로 수정이 반복되지 않습니다. 도형 차이와 경미한 차이는 정답표 앞 **검수 노트** 표에 남고, 사람이 최종 확인합니다.
- **도형:** 그림 선지와 보기 상자 안 도형을 지원합니다. 렌더한 그림을 엔진이 직접 재서 겹친 라벨을 옮기고, 문제 글의 위치 조건(중점, 원 위의 점 등)·원본과의 비율·접할 듯 말 듯한 선을 알려 줍니다.
- **수식:** 프라임(′), 쉼표, 적분 dx, 행렬 칸의 띄어쓰기를 시험지 관행에 맞췄습니다.
- **여러 시험지 동시 작업:** 에이전트를 여러 개 띄워도 한글 출력이 차례를 기다려 모두 완료됩니다.
- **중단 후 재시작:** 작업 도중 끊었다가 다시 시작해도, 남은 한글 프로세스나 잠금 파일 때문에 막히지 않습니다.
- **새로 설치할 프로그램이나 Python 패키지는 없습니다.** [의존성 변화](docs/DEPENDENCIES.md) · [전체 업데이트 내역](docs/CHANGELOG-v2.7.9.md)

## 처음 사용하는 분: 세 단계

### 1. 준비물 확인

| 준비물 | 설명 |
|---|---|
| Windows PC | 현재 한글 출력 기능에 필요합니다. Mac·Linux만으로 같은 기능을 사용할 수 없습니다. |
| 설치된 한컴오피스 한글 | HWP 편집이 가능한 데스크톱 한글이 필요합니다. 뷰어·웹 한글만으로는 부족합니다. |
| AI 에이전트 | 파일 접근, 이미지 보기, 서브에이전트, MCP 연결 기능이 필요합니다. 검증 환경은 Antigravity CLI와 opencode입니다. |
| Python 3.12 | 에이전트가 설치 여부를 확인하고 전용 실행 환경을 만듭니다. |
| TeX와 TikZ | 도형을 그릴 때 필요합니다. TeX Live 또는 MiKTeX 등의 환경을 에이전트가 확인합니다. XeLaTeX, LuaLaTeX, pdfLaTeX 중 하나면 됩니다. |
| 한글 글꼴·자동화 환경 | 양식의 `한컴 윤고딕 720` 등 글꼴과 한글 자동화·보안 모듈은 PC에서 확인해야 합니다. |

한글 프로그램, 글꼴, 모델 이용권·API 비용은 포함하지 않습니다. 설치가 끝났다는 안내와 실제 시험지가 정상 출력됐다는 검증은 구분합니다.

### 2. 에이전트에게 설치 요청

아래 내용을 복사해 붙여넣으세요. 설치 과정에서 에이전트가 코드를 실행해도 직접 코딩할 필요는 없습니다. 이미 이전 버전을 쓰고 있다면 아래 [업데이트 프롬프트](#이전-버전에서-업데이트)를 쓰세요.

```text
https://github.com/acb0808/hwp-exam-restoration 의 v2.7.9를 설치해주세요.
저는 코딩을 모릅니다. 저장소의 AGENT_INSTALL.md를 먼저 읽고,
Windows·한글·Python·TeX 준비 상태 확인, 기존 설정 백업,
스킬 설치, 필요한 라이브러리 설치, hwp-restoration MCP 등록과 연결 확인을 진행해주세요.
기존 스킬과 다른 MCP 설정, 작업 파일은 보존해주세요.
지원되지 않는 앱이면 설정을 추측해서 바꾸지 말고 필요한 조건을 알려주세요.
제가 직접 해야 하는 재연결·프로그램 설치·로그인만 쉬운 말로 안내해주세요.
API 키나 비밀번호를 채팅에 붙여넣도록 요구하지 말고, 결제나 과금 벤치마크는 실행하지 마세요.
마지막에 설치된 버전, 실제 확인된 항목, 아직 확인하지 못한 항목과 사용 방법을 알려주세요.
```

다운로드가 필요하면 [v2.7.9 배포 파일](https://github.com/acb0808/hwp-exam-restoration/releases/tag/v2.7.9)을 이용하세요. 소스 전체를 복사할 필요 없이 ZIP 안의 `hwp-exam-restoration` 폴더가 스킬입니다. 에이전트가 GitHub 페이지를 읽지 못하면 배포 ZIP을 내려받아 에이전트에게 경로를 알려주세요.

### 이전 버전에서 업데이트

이미 설치해 쓰고 있다면 아래 내용을 같은 에이전트에게 보내세요. 새로 설치할 프로그램이나 Python 패키지는 없습니다.

```text
설치된 hwp-exam-restoration 스킬을 https://github.com/acb0808/hwp-exam-restoration 의 v2.7.9로 업데이트해주세요.
저는 코딩을 모릅니다. 저장소의 AGENT_INSTALL.md에서 "v2.7.3에서 업데이트할 때"를 먼저 읽고 그대로 진행해주세요.
지금 설치된 스킬 폴더와 버전을 확인하고, 바꾸기 전에 날짜를 붙인 백업을 만들어주세요.
배포 ZIP과 SHA256SUMS.txt로 파일을 확인한 뒤 스킬 폴더를 번들 전체로 바꾸고,
기존 .mcp-venv와 제 작업 폴더·결과물, 다른 스킬과 다른 MCP 설정은 그대로 두세요.
예전에 역할 파일을 따로 설치해 둔 사본이 있으면 같은 버전으로 갱신해주세요.
진행 중인 복원 작업이 있으면 업데이트하기 전에 알려주세요.
마지막에 hwp-restoration MCP를 다시 연결하는 방법만 쉬운 말로 알려주고,
재연결 뒤 첫 hwp_prepare 응답의 runtime_version이 2.7.9인지 확인할 수 있게 해주세요.
API 키나 비밀번호를 묻지 말고, 결제나 과금 벤치마크는 실행하지 마세요.
끝나면 이전 버전, 새 버전, 백업 위치, 확인된 항목과 아직 확인하지 못한 항목을 알려주세요.
```

### 3. PDF 복원 요청

MCP를 재연결한 뒤, PDF를 첨부하거나 PC의 파일 위치를 알려주고 아래처럼 요청하세요.

```text
설치된 hwp-exam-restoration 스킬로 이 수학 시험지를 복원해주세요.
스킬의 SKILL.md와 MCP 절차를 따라 문제 쪽만 복원하고,
수식과 필요한 도형을 넣고 마지막 페이지에 정답표를 만들어주세요.
별도 검수자가 원본과 실제 출력을 확인하도록 해주세요.
읽을 수 없는 부분은 추측하지 말고 해당 문항만 알려주세요.
최종 HWP, HWPX, 확인용 PDF와 남은 문제를 알려주세요.
```

## 복원되는 것

- 문제 쪽의 번호, 본문, 조건, 보기, 선지, 배점과 편집 가능한 수식.
- 원본의 쪽·단·문항 순서와 선택지 행 구분을 반영한 고정 시험지 양식.
- 필요한 도형을 TikZ로 다시 그린 삽입 그림. **HWP 안에서 점·선 각각을 편집하는 개체로 제공되는 것은 아닙니다.** 원본 TeX는 작업 폴더에 남습니다.
- 마지막 정답표. 원본 정답을 그대로 믿지 않고 작성·검수 과정에서 확인합니다.
- 정답표 앞의 **검수 노트** 표. 자동 검수가 고치지 않고 넘긴 차이(주로 도형의 세부 모양)를 쪽·문항별로 적습니다. 한글에서 바로 고칠 수 있는 일반 표입니다.
- HWP/HWPX와 출력 확인용 PDF.

표지, 빈 면, 안내, 기존 해설·정답 페이지, 필기와 원본 장식은 복원 대상이 아닙니다. 원본과 똑같은 좌표를 복제하는 작업이 아니라 문제를 편집 가능한 시험지로 다시 구성하는 작업입니다.

## 현재 확인된 한계

AI가 도형의 선이나 기호를 잘못 만들거나 검수에서 놓칠 수 있습니다. 엔진이 재는 검사도 일부 오류만 잡습니다. **배포 전 사람이 최종 PDF, 검수 노트 표, 정답표를 확인해주세요.**

Antigravity(Gemini 3.8 Flash High)의 5시간 한도로는 시험지 하나에 고등학교 4쪽 약 8%, 고등학교 6쪽 약 11%, 도형이 많은 중학교 약 16%가 들었습니다(어림식: 1.7 × 문제 쪽 수 + 0.33 × 도형 수). 남은 한도가 예상 합계보다 10% 이상 많을 때 시작하세요. 같은 시험지라도 실행마다 시간과 사용량이 크게 다르고, 다른 모델이나 effort에서는 같은 결과를 보장하지 않습니다. [한도 가이드라인과 검증 결과](docs/CHECKPOINT.md)

시험지와 결과물은 작업 폴더에 저장됩니다. 선택한 AI 에이전트가 원본 이미지·내용을 모델 서비스로 전송할 수 있으므로, 공개할 수 없는 자료는 사용하는 서비스의 데이터 정책을 확인하세요. 이 저장소에는 시험지 원본·실제 복원본·API 키·개인 대화 기록을 넣지 않았습니다.

## 개발자용 정보

스킬과 런타임은 `hwp-exam-restoration/`에 함께 들어 있습니다. 다른 스킬이나 외부 pdf2HWP 프로젝트를 추가로 받을 필요가 없습니다. 번들 파일 해시는 `BUNDLE-MANIFEST.json`, 동봉 코드 출처는 `runtime/sources.json`에 있습니다.

프로젝트 코드의 사용 조건은 [MIT 라이선스](LICENSE), 외부 프로그램·패키지에 관한 정보는 [출처 안내](THIRD_PARTY_NOTICES.md)를 확인하세요. 오류 제보에는 버전과 오류 문구를 적되 API 키·개인 시험지·전체 대화 로그는 올리지 마세요.
